# Work packages

Authored work packages for bounded, governed delivery live here:

```text
05-work-packages/WP-LRT-<SLUG>-NNNN-slug/package.yaml
```

Each package declares its scope, authority boundary, actions, verification, and disposition.
For research packages, `commitment: stretch` means the commitment is to reach and record a
disciplined resolution; a negative result can complete the package successfully.

Before allocating any new work-package UID, check the current repository and open issues for
collisions and semantic duplicates. Current repository state is authoritative.
