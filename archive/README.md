# LRT Archives

This directory contains archived/deprecated content organized by category. All historical work is preserved for reference and traceability.

## Directory Structure

```
archive/
├── approach-2-reference/    # Second approach iteration (pre-refactor)
├── lean-d-series/           # Deprecated D-series Lean formalization attempts
├── theory-pre-refactor/     # Theory documents from March 2026 pre-refactor
├── theory-versions/         # Superseded theory document versions
├── docs_v1/                 # Version 1 documentation
└── README.md                # This file
```

## Contents

### approach-2-reference/
Reference materials from the second major approach to formalizing LRT. Contains:
- Earlier Lean formalization attempts
- Lessons learned documentation
- Root documentation from that iteration

### lean-d-series/
Deprecated D-series Lean files that were part of an experimental formalization approach. Preserved for reference but no longer actively maintained.

### theory-pre-refactor/
Theory documents from before the March 2026 consolidation, including:
- Born Rule paper variants (20251231)
- GR Extension work (20251231)
- Hilbert Space Derivation (20251231)
- QFT Statistics Paper (20251231)
- Position papers and philosophy documents (20260109)
- LRT-MASTER.md snapshots from before refactoring

### theory-versions/
Superseded versions of major theory documents:
- Logic_Realism_Theory_Master_* backups
- v2, v3 theory document variants
- Paper drafts and restructuring work
- Dated session snapshots

## Archive Policy

1. **Never delete** - only move deprecated content here
2. **Preserve history** - use `git mv` for all moves
3. **Date prefixes** - when applicable, include dates in directory names
4. **Readme files** - each major subdirectory should have its own README
